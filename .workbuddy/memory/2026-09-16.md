## 百度站点验证文件访问不到 —— 定位结论

**现象**：`docs/public/baidu_verify_codeva-FUmMC9FhKu.html`（内容 `ebfe180214873bf220fbd8504d777686`）访问不到。

**实测证据**：
- 本地 dev（`vitepress dev docs --port 5199`）与 preview（`--port 5198`）请求 `/baidu_verify_codeva-FUmMC9FhKu.html` 均返回 **200**，内容正确 → 本地链路无问题。
  - 注意：Vite dev 默认绑 IPv6，探测要用 `::1`；preview（sirv）绑 IPv4 `127.0.0.1`。
- 线上 `https://suyan.zhangjh.cn/baidu_verify_codeva-FUmMC9FhKu.html` → **404**（VitePress 404 页，`server: cloudflare`）。
- `git status` 该文件为 **未跟踪 `??`** → Cloudflare Pages 构建产物里没有它，这是线上 404 的直接原因。

**线上另一个坑（实测）**：Cloudflare Pages 会剥离 `.html` 扩展名 —— `/download.html` 返回 **308 → /download**。所以文件验证方式下，百度请求 `.html` 会先吃 308。


`vitepress build docs` 实测通过（EXIT=0）；dist 中 index.html / download.html / guide/install.html / 404.html 均已注入，且位于 `</head>` 之前。

`docs/public/baidu_verify_codeva-FUmMC9FhKu.html` 保留作兜底，未删除；未 commit/push（等用户过目）。
