# 自定义输入方案

素言基于 RIME 引擎，除了内置的雾凇拼音、双拼、五笔 86 之外，还支持按需启用更多输入方案：**预置模板一键勾选**（7 种双拼码表、注音等），以及**上传自己的 RIME 方案文件**（长尾小众方案自理）。修改确认后自动部署，方案随即出现在切换菜单中。

## 打开方式

1. 右键点击托盘中的「中/EN」语言指示器，打开设置菜单（详见 [FAQ：设置菜单怎么打开？](/guide/faq#设置菜单怎么打开))。
2. 进入「基本设置」，点击 **「输入方案管理...」** 按钮，打开「输入方案管理」对话框。
    <img src="/custom-schemes-entry.png" alt="基本设置菜单中的「输入方案管理...」入口" width="419" height="412" loading="lazy" decoding="async">

## 预置方案：一键勾选

「预置方案」分组中的模板随安装包发布，但默认不启用——勾选即启用，取消勾选即停用：

| 预置方案 | 说明 |
| :--- | :--- |
| 雾凇拼音（全拼） | 基于雾凇拼音配置的全拼方案 |
| 双拼 + 码表下拉 | 单选一种码表（见下表），是设置项、不需要快捷键 |
| 注音（模板） | 面向台湾用户及习惯注音输入的用户 |
| 五笔 86 | 基于极点五笔 86 码表与词库调校 |

双拼码表下拉提供 7 种选择：

- **小鹤双拼**（默认）、自然码、微软双拼、智能ABC、搜狗双拼、紫光双拼、拼音加加

::: tip 双拼码表切换是设置项
双拼码表通过下拉单选切换，**不需要快捷键**；方案大类之间（拼音 ⇄ 双拼 ⇄ 五笔 ⇄ 注音）的快捷键切换保留——比如五笔用户遇到不会拆的字时，可切拼音救急。
:::

修改完成后点击 **「确定」**，素言会自动重新部署 Rime，新方案随即出现在方案切换菜单中；点击「取消」则放弃本次修改。

## 上传自己的 RIME 方案

预置模板之外的冷门方案（如其他双拼变体、方言拼音等），可以手动上传：

1. 在「输入方案管理」对话框中点击 **「上传输入方案...」**。
2. 选择本地的 RIME 方案文件（`.schema.yaml`）。
3. 文件通过校验后出现在「当前启用的方案」列表中，点击「确定」自动部署生效。

上传文件需满足以下校验（不满足会直接提示原因）：

- 是合法的 YAML 文件，且不超过 1MB；
- 包含 `schema/schema_id`（仅允许字母、数字、下划线、点）与 `schema/name`；
- 不含 Lua 脚本（安全限制，含 Lua 引用的方案会被拒绝）。

「当前启用的方案」列表会汇总所有已启用的预置方案与上传的自定义方案；**只有上传的自定义方案可以选中后点击「删除选中」移除**，预置方案通过取消勾选停用。

## 注意事项

- **支持边界**：预置模板与自定义方案的打字体验、键位正确性**不在官方技术支持范围内**（小众方案长尾自理）；上传前请确认方案文件来自可信来源。
- **不支持模糊音**：自定义方案与内置双拼一致，不支持模糊音设置。
