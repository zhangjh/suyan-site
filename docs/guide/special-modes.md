# 特殊输入模式

素言基于 RIME 引擎与雾凇拼音方案，除了正常打字外，还内置了一批「特殊输入模式」，用于快速输入符号、日期、大写金额等内容。

如果你是第一次接触 RIME，推荐把本页通读一遍——这些模式**在其他输入法里通常不存在**，但一旦熟悉会非常高效。

## 速查表

| 用途 | 输入 | 示例 |
| :--- | :--- | :--- |
| 符号大全 | `vfh` | 唤出标点、箭头、数学符号等候选 |
| Emoji 表情 | `vvv` | 唤出 Emoji 候选 |
| 日期 | `rq` | `2026-04-20` / `2026年4月20日` |
| 时间 | `sj` | `14:30` / `14时30分` |
| 星期 | `xq` | `星期一` |
| 日期+时间 | `dt` | `2026-04-20 14:30:00` |
| 时间戳 | `ts` | `1745136000` |
| 农历 | `nl` | `二零二六年三月初四` |
| 大写金额 | `R` + 数字 | `R1234.56` → `壹仟贰佰叁拾肆元伍角陆分` |
| Unicode 反查 | `U` + 十六进制 | `U4e2d` → `中` |
| 英文直通 | 大写字母开头 | `Hello` + 空格 → `Hello` |
| 整词上屏 | 拼音 + `;` | `nihao;` → `你好` |

## 符号输入（v 模式）

在其他输入法里，特殊符号通常要靠「软键盘」慢慢找。在素言里，只需要输入 `vfh`（**v**符**h**）即可唤出符号大全，包含标点、括号、箭头、数学符号、希腊字母等。

```
vfh → （唤出符号候选，按数字键或翻页选择）
```

输入 `vvv` 可以唤出 Emoji 表情候选：

```
vvv → 😀 😂 🤣 … （当前内置 11 个常用 Emoji）
```

此外，正常打字时 Emoji 也会作为候选词出现——输入对应汉字的拼音即可：

```
xiao → 笑 … 😄 😂
ku   → 哭 … 😢 😭
```

翻页找到 Emoji 候选选中即可上屏，无需记忆额外编码。

> 字母 `v` 在拼音里本身不使用，因此被 RIME 占用为特殊功能前缀。

## 日期与时间

用于快速插入当前日期、时间、星期等信息，写日志、填表、标注版本号时非常方便。

| 编码 | 含义 | 输出示例 |
| :--- | :--- | :--- |
| `rq` | 日期 | `2026-04-20`、`2026年4月20日`、`二〇二六年四月二十日` |
| `sj` | 时间 | `14:30`、`14时30分` |
| `xq` | 星期 | `星期一`、`周一`、`Monday` |
| `dt` | 日期时间 | `2026-04-20 14:30:00` |
| `ts` | Unix 时间戳 | `1745136000` |
| `nl` | 农历日期 | `二零二六年三月初四` |

每种编码通常会给出多种格式候选，用数字键选择即可。

## 大写金额（R 模式）

写合同、开发票、记账时，用于快速将阿拉伯数字转为中文大写金额。

```
R123       → 壹佰贰拾叁
R1234.56   → 壹仟贰佰叁拾肆元伍角陆分
```

注意是**大写** `R`，小写 `r` 不会触发该功能。

## Unicode 反查（U 模式）

已知某个字符的 Unicode 码点（十六进制），但不记得怎么打时使用。

```
U4e2d → 中
U738b → 王
```

常用于输入生僻字、专名用字。

## 英文直通

需要在中文输入状态下偶尔输入英文单词（如人名、品牌、专业术语）时，**直接以大写字母开头**输入即可，按空格上屏。

```
Hello   + 空格 → Hello
GitHub  + 空格 → GitHub
```

::: warning 使用限制
英文直通模式下**中间不能包含数字**——数字键会被识别为候选词的选择键。如果需要输入 `GitHub2025` 这样的混合内容，建议分两次输入，或在输入英文部分时临时切换到英文模式（`Shift`）。
:::

## 整词上屏（分号快捷键）

连续输入一整段拼音后，如果希望**把当前拼音作为整词直接上屏**（等价于选中第一候选），在拼音末尾追加一个分号 `;`。

```
nihao;          → 你好
woshizhongguoren;  → 我是中国人
```

相比按空格选第一候选，分号的位置更接近回车，长拼音整词上屏时手指移动更少。

## 小贴士

- 以上所有前缀（`v`、`R`、`U`、`rq` 等）都是 RIME 约定用法。如果你把这些编码本身作为拼音输入的一部分，系统会优先按特殊模式处理。
- 若某次输入意外触发了特殊模式，按 `Esc` 清空当前输入即可。
- 更多 RIME 通用技巧可参考 [雾凇拼音官方文档](https://github.com/iDvel/rime-ice)。
