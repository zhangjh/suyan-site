## 🎙️ 离线语音输入

素言是目前极少数支持**完全离线语音识别**的桌面输入法。

内置高性能本地语音识别引擎，你的音频数据**不经过任何服务器**，从麦克风到文字的全过程在本机完成。

- 🔇 **零上传**：音频数据不出本机，从根源杜绝语音隐私泄露
- ⚡ **低延迟**：本地推理，说完即出字，无需等待网络响应
- 🎯 **中文优化**：针对普通话场景调优，日常对话、会议记录均可胜任
- ⌨️ **无缝切换**：快捷键一键启动语音输入，与打字模式自由切换

> 当商业输入法的语音功能把你的每一句话都传上云端时，素言让语音输入回归它本该有的样子——只属于你。

## 为什么选择素言？

> "在这个信息过载的时代，我们只想找回那个**即开即用、干干净净**的输入框。"

### ⚡️ 核心特性

- **跨平台统一体验**：Windows 与 macOS 完美复刻，无论在哪里办公，手感始终如一。
- **离线语音输入**：内置本地语音识别引擎，音频不上传，说话即出字。
- **临时英文模式**：无需切换输入法，直接在中文模式下流畅输入英文单词，代码/变量名输入不再断流。
- **自定义皮肤系统**：支持明暗主题自动切换，更支持完全自定义。不仅好用，更要好看。
- **灵活布局切换**：同时支持 **横排** 与 **竖排** 布局，适应不同阅读习惯与屏幕空间。
- **超大候选视野**：支持扩展候选框，一次最多展示 **5x9=45** 个候选词。支持翻页查找，生僻词不再难找。

### 🔐 技术透明

素言基于 [RIME 中州韵](https://rime.im/) 开源引擎构建，词库来自社区维护的[雾凇拼音](https://github.com/iDvel/rime-ice)。核心输入逻辑由经过十余年验证的开源代码驱动，不存在隐藏的数据采集后门。

## 🏢 企业级私有化定制

素言不仅是一款纯净的个人工具，更为追求数据主权的企业提供深度定制化方案。

- 🌐 **内网大模型对接**：支持对接企业私有化部署的 Qwen、Llama 等大模型，实现流式 AI 语音录入与智能纠错。
- 📦 **私有化分发部署**：提供专用的企业版安装包，预置企业内网配置，一键分发，无外部网络依赖。
- 📚 **行业专业词库**：针对医疗、法律、金融等行业提供专属词库定制，大幅提升专业领域输入效率。
- 🛡️ **安全合规审计**：完全符合政企单位对敏感数据的审计要求，数据不经由任何公有云。

> **商业合作咨询**：如有私有化部署、大模型对接或定制化开发需求，欢迎通过 [联系我们](/guide/contact) 页面获取专业支持。
