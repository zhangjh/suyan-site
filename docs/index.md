## 🎙️ 离线语音输入

素言是目前极少数支持**完全离线语音识别**的桌面输入法。

内置高性能本地语音识别引擎，你的音频数据**不经过任何服务器**，从麦克风到文字的全过程在本机完成。

- 🔇 **零上传**：音频数据不出本机，从根源杜绝语音隐私泄露
- ⚡ **低延迟**：本地推理，说完即出字，无需等待网络响应
- 🎯 **中文优化**：针对普通话场景调优，日常对话、会议记录均可胜任
- ⌨️ **无缝切换**：快捷键一键启动语音输入，与打字模式自由切换

> 当商业输入法的语音功能把你的每一句话都传上云端时，素言让语音输入回归它本该有的样子——只属于你。

## ☁️ 云同步：多端一致的输入体验

办公场景往往跨多台设备——公司电脑、家里笔记本、不同系统的桌面。素言 v5.0 引入**端到端加密的云同步**，让你的输入习惯随账号流转，而非困在单机。

登录账号后，以下数据可在多端同步：

- ⚙️ **配置与偏好**：方案配置、皮肤设定、快捷键等，新装设备秒级复刻你的环境
- 📚 **自定义词库**：你添加的短语、行业术语、专属词库一处添加，处处可用
- 📊 **输入词频**：高频词、调频记录同步共享，确保"常用词"在各端排序一致，越用越懂你

### 🔐 隐私优先：端到端加密盲盒

同步功能绝不上传按键流，仅同步词库与词频记录。同步数据在本地通过 **AES-256** 加密后上传，服务器仅作为"盲盒"存储。

> 多端协同不该以牺牲隐私为代价。素言让你既享受云的便利，又保留本地的纯粹。

## 🤖 AI 划词翻译：系统级智能翻译

看英文文档、读外文资料、回复海外同事——翻译已经成为高频生产力场景。素言 v5.0 内置 **AI LLM 翻译引擎**，无需切换第三方软件，选中即译。

- 🎯 **系统级划词翻译**：基于系统辅助能力（Windows UIA / macOS Accessibility），覆盖**所有桌面应用**——Word、PDF、IDE、笔记软件、聊天工具，不仅是浏览器
- 🌐 **超越浏览器插件**：Chrome 翻译插件只能在浏览器内运行，素言划词翻译覆盖整个操作系统
- ⚡ **流式响应**：基于 OpenAI 兼容 SSE 流式接口，逐字返回翻译结果，长文本不卡顿
- 🏠 **企业版专属**：企业版可对接私有部署的 Qwen、Llama 等内网模型，数据不出企业边界

> 选中→翻译→继续工作。翻译不该打断你的思路，更不该被浏览器框死。

## 为什么选择素言？

> "在这个信息过载的时代，我们只想找回那个**即开即用、干干净净**的输入框。"

### ⚡️ 核心特性

- **三端跨平台统一体验**：Windows、macOS、Ubuntu 完美复刻，无论在哪里办公，手感始终如一。
- **端到端加密云同步**：登录账号同步配置、词库与词频，多端办公无缝衔接，数据加密盲盒存储。
- **AI 系统级划词翻译**：内置 LLM 翻译引擎，覆盖所有桌面应用，比浏览器插件更彻底。
- **离线语音输入**：内置本地语音识别引擎，音频不上传，说话即出字。
- **临时英文模式**：无需切换输入法，直接在中文模式下流畅输入英文单词，代码/变量名输入不再断流。
- **自定义皮肤系统**：支持明暗主题自动切换，更支持完全自定义。不仅好用，更要好看。
- **灵活布局切换**：同时支持 **横排** 与 **竖排** 布局，适应不同阅读习惯与屏幕空间。
- **超大候选视野**：支持扩展候选框，一次最多展示 **5x9=45** 个候选词。支持翻页查找，生僻词不再难找。

### 🔐 技术透明

素言基于 [RIME 中州韵](https://rime.im/) 开源引擎构建，词库来自社区维护的[雾凇拼音](https://github.com/iDvel/rime-ice)。核心输入逻辑由经过十余年验证的开源代码驱动，不存在隐藏的数据采集后门。

## 🏢 企业级私有化定制

员工每天通过输入法键入大量敏感信息——客户名称、合同金额、内部代号。商业输入法将这些击键数据上传至公有云，素言从根本上杜绝这一风险。

### 核心能力

- 🌐 **内网大模型对接**：对接企业私有部署的 Qwen、Llama 等大模型，实现 AI 辅助输入、智能纠错与系统级划词翻译，所有数据仅在企业内网流转，不触达任何外部服务器。
- ☁️ **企业级同步与账号体系**：基于统一账号体系实现云同步（词库+词频+配置），支持企业自有 SSO 对接，员工换机即恢复全部输入习惯。
- 📦 **企业级分发部署**：提供独立企业版安装包（支持 MSI/PKG/DEB），预置内网配置，兼容 MDM 统一推送，IT 部门可一键批量部署。
- 📚 **行业专属词库**：针对医疗、法律、金融、制造等行业定制专业词库，大幅减少专业术语的输入成本。
- 🛡️ **安全合规**：输入数据全程本地处理，满足等保、数据出境等合规审计要求，适用于政企、军工、金融等高安全场景。

### 交付方式

| 项目 | 说明 |
| :--- | :--- |
| **部署形式** | 独立安装包（Windows/macOS/Ubuntu）/ MDM 统一推送 / 内网分发平台集成 |
| **大模型对接** | 支持 OpenAI 兼容接口，可对接企业已有内网模型服务 |
| **同步方案** | 端到端加密同步，支持企业内网自建同步服务 |
| **词库定制** | 提供词库导入工具 + 专业领域词库制作服务 |
| **技术支持** | 专属对接群 + 定期版本更新 + SLA 保障 |
